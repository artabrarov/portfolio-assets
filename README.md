# portfolio-assets

Files served to [arthurabrarov.com](https://arthurabrarov.com), my portfolio site. The site is built in Framer; this repo holds the scripts and media it loads, published with GitHub Pages at `https://artabrarov.github.io/portfolio-assets/`.

It isn't a library or a template, just the assets behind one site, kept in the open.

## What's here

| Folder | What it is | Used by |
|---|---|---|
| [`code/`](code/) | The emoji clicker game on the homepage | One `<script>` tag in Framer's site-wide custom code |
| [`sites/`](sites/) | Screenshots and hover videos of portfolio sites I admire | The gallery on [arthurabrarov.com/sites](https://arthurabrarov.com/sites) |

## How changes go live

Push to `main`. GitHub Pages republishes within a few minutes (it caches for about 10), and the site picks up the new files with no Framer step.

## The sites in `sites/`

The screenshots and clips in `sites/` show other people's websites, and those designs belong to their creators. They're here only to feature that work in the gallery, where each card links to the original site.
